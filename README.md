Token Ludo

Token Ludo is a fast, 100% offline 16-token zero-sum dice duel for Android crafted by Asif Labs. Start 8 vs 8 on a tactile tabletop—every roll steals tokens from your rival, overshoots pass the turn, and an exact finishing roll claims all 16 tokens for a Clean Sweep.

This repository hosts the official landing page and interactive web demo at asiflabs-dev.github.io.

Key Highlights

2-Player Pass-and-Play & Solo Bot AI: Duel a friend face-to-face on one device or challenge the offline Bot.

Multiple Match Formats: Play Quick Duel, Best of 3, or Best of 5 series.

15-Second Turn Timer & Coin Toss: Fast-paced turns with a fair opening toss and Left/Center/Right dice positioning.

8 Handcrafted Themes & 4 Board Surfaces: Switch between Emerald Felt, Matte Obsidian, Royal Marble, and more.

Privacy-First & Zero Sign-Up: No accounts, no sensitive permissions, and local-only match history.
